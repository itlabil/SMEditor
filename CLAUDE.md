# SMEditor

App web lokal (Go + Vue) dan plugin Premiere (CEP) untuk membuat highlight esport.

Sebelum bekerja, baca:

- `.agents/rules/architecture.md`
- `.agents/rules/conventions.md`
- `docs/prd.md`, `docs/flow.md`, `docs/erd.md`, `docs/sequence.md`
- `docs/tickets.md` — kerjakan satu tiket per sesi, sesuai kriteria terima dan Definition of Done.

Skill khusus project ada di `.agents/skills/`. Baca `SKILL.md` yang relevan sebelum mengerjakan bagian terkait.

Jika menemukan pola kode yang buruk dan belum ada aturannya, usulkan aturan baru untuk `.agents/rules/`.
